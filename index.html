Nest Notification Bridge

Nest Notification Bridge is a personal, non-commercial, single-user software project. It connects the project owner's own Google Nest devices to the owner's private home server so the owner can receive device notifications and use camera and device features that the owner has explicitly authorized.

How it works

The bridge uses Google's Smart Device Management API and Google sign-in. During authorization, Google shows the requested access and the account owner chooses which home and devices to share with the project. The bridge communicates with Google's API only to provide the requested functionality to that account owner.

What it accesses

Depending on the devices authorized by the owner, the API can provide device names, rooms, device status and traits, camera event information, snapshots, and live-stream connection details. The bridge does not provide a public service and does not create accounts for other people.

Control and privacy

The owner can revoke this project's access at any time from the Google Account's third-party access settings. Details about information handling are in the Privacy Policy.

This is an independent personal project and is not affiliated with or endorsed by Google or Google Nest.
